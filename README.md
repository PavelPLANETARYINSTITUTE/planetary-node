# planetary-node (Планетарный узел)

Децентрализованный основной механизм Планетарного института. Постквантовый P2P-узел Web4, объединяющий независимую науку, автоматизированную междисциплинарную фильтрацию с помощью ИИ и адаптивное управление экосистемой с помощью глобальных индикаторов (реперов). Свободен от политического и корпоративного влияния.

## 🌌 Манифест Планетарного Института

Земля — это единый космический корабль в безграничной пустоте Вселенной. У нас нет запасного дома и нет времени на внутренние распри. С высоты орбиты на нашей планете нет прочерченных границ, таможенных постов и разделения на «своих» и «чужих». Эти барьеры существуют только в нашем сознании.

Мы, человечество, подошли к опасной черте. Вектор нашего развития сломан: обладая технологиями XXI века, наш коллективный разум во многом остался на уровне пещерного эгоизма. Мы тратим колоссальные ресурсы, интеллект лучших ученых и триллионы средств на создание оружия и защиту друг от друга, в то время как экологические, ресурсные и космические вызовы угрожают самому существованию нашего вида.

Планетарный Институт создается как альтернативный путь. Это точка сборки нового, зрелого человечества, готового взять на себя ответственность за будущее своего дома и выйти к звездам.

### Основные принципы:
1. **Высшая цель цивилизации:** Сохранение жизни на Земле, преодоление глобальных кризисов и переход к осознанному изучению и освоению Вселенной.
2. **Принцип Абсолютного Равенства:** Внутри Института не существует деления людей по национальности, расе, цвету кожи или религиозным взглядам. Каждый человек — полноправный член экипажа корабля «Земля».
3. **Свобода от политического и корпоративного влияния:** Полная изоляция от политических партий, демагогии, популизма и финансового лобби. Управление строится на принципах технократии и меритократии — власти знаний и доказанной эффективности.
4. **Симбиоз Науки и ИИ:** Независимое экспертное сообщество и Глобальный ИИ, в ядро которого жестко заложены принципы защиты человечества и биосферы.
5. **Метод Реперов:** Адаптивное управление через строгие контрольные точки эффективности.

## 💻 Инструкция по запуску тестовой ноды (v0.1-alpha)

Нода работает в изолированном Docker-контейнере, полностью безопасна для хост-системы и использует P2P-сеть IPFS для децентрализованного обмена данными.

### Требования:
* ОС: Linux / Windows (WSL2) / macOS
* Docker Desktop

### Быстрый запуск:
Откройте терминал и выполните следующую команду:

```bash
docker run -d --name planetary-node-v1 -p 4001:4001 -p 8080:8080 -v ~/planetary_data:/data/pi planetaryinstitute/node:latest
```

После запуска перейдите в браузере по адресу `http://localhost:8080` для инициализации вашего анонимного криптографического ID в сети.
